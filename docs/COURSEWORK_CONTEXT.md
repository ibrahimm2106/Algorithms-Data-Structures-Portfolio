# Coursework context

This portfolio repository is based on work from **Algorithms (CMP020N203A)**. It combines material from two individual coursework components into one cleaner technical portfolio.

## Coursework 1 — programming with linear data structures

The brief required two programs:

1. **String Processor** — process alternating strings and `+` / `-` operators from left to right, selecting an appropriate queue or stack data structure.
2. **Online Store** — use C++ linked lists and pointers to manage current, processed and returned purchases. Required operations included adding, processing, returning, sorting, searching and printing purchases.

The portfolio version keeps those concepts while improving structure, deterministic testing and documentation.

## Coursework 2 — algorithms and data structures report

The report covered:

- Merge Sort
- Quick Sort using the final element as pivot
- Insertion Sort
- Dijkstra's shortest-path algorithm
- A 26-bucket alphabet hash table using chaining
- A binary search tree built from name characters

The original Coursework 2 submission was report/diagram focused. The executable Python modules in this repository are **portfolio companion implementations added after the coursework** so the algorithms can be run and tested directly.

## Academic transparency

This repository is a post-coursework portfolio presentation. It is not presented as the exact original submission, and the added tests, CI, modularisation and companion implementations are clearly portfolio enhancements.
